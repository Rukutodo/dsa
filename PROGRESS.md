## Conventions

Each solved problem gets its own `.cpp` file inside the relevant step folder, named after the problem (kebab-case), e.g. `problems/01-basics/count-digits.cpp`. Each file starts with a comment block:

```cpp
// Problem: <name / one-line statement>
// Link: <source URL if applicable>
// Approach: <short summary>
// Time: O(...)  Space: O(...)
```
